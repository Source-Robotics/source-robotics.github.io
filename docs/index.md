# Source Robotics documentation

Manuals and guides for the open-source robot arms, grippers and motor controllers by
[Source Robotics](https://source-robotics.com). Each product has its own site, with its own search.

<div class="grid cards" markdown>

-   :material-hand-back-left-outline:{ .lg .middle } **SSG-48 gripper**
